## What the site is

The site is the public map of the work: Coder, Creator, Learner, Gamer — plus the AI-safety thread **Quantifying Everything → Non-Sovereignty → Mirror Deterrence**.

This repository is that site. Open-source project code lives in separate repos; each project below that has a public page is linked from here.
